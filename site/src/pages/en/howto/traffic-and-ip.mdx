## Checking traffic

- **Provider dashboard**: BandwagonHost's KiwiVM home page shows this month's traffic and reset date; other providers show it on the server page.
- **In your apps**: tell the AI your monthly quota and reset day when deploying (manual route: add `--quota-gb 1000 --reset-day 1` to the `init` line) and Clash Verge and Shadowrocket show your usage. Forgot? Ask the AI to add it.

<Callout type="tip">
Speed tests are very data-hungry — one run can use several to tens of GB. Video uses a lot too. A few hundred GB to 1 TB a month is usually enough for a household.
</Callout>

## When to change the IP

**First confirm it's the IP**: several networks (mobile data, different Wi-Fi, different carriers) all fail, yet an AI health check says the server is fine. Then the IP has probably been restricted locally. Configuration changes won't help — you need a new IP.

## How

- Some providers offer an IP change (free or paid) in the dashboard;
- otherwise, open a ticket and ask.

## Afterwards

The certificate and subscription URLs are tied to the IP, so a new IP means reconfiguring:

1. Give the new IP to the AI and ask it to reconfigure the server with the setup (or use step 3's manual route with the new IP).
2. On every device, **delete the old subscription and import the new one** (the IP in the URL changed).
3. Check everything as in step 5.
